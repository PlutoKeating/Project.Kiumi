# 秀米工作台交互规格

本文件记录对 `xiumi.us/studio/v5` 编辑器操作能力的实测与对照。
快捷键表直接取自编辑器包内的 `studio/services/shortcutBinder` 模块（38 条绑定，原文照录），
不依赖界面截图推断。

---

## 1. 画布模型

- 画布是**块（comp）树**，不是富文本流：每块有自己的骨架、样式与可编辑槽位。
- 块有「选中」与「编辑中」两种状态：
  - 选中：出现框线与工具条，可拖动、删除、复制。
  - 编辑中：文字块进入 contenteditable，光标在字间，工具条切到文字格式。
- 布局块（group/container）是**投放区**：可往里再放块，形成嵌套；投放区有静态与绝对两种定位语义。
- 块与块之间的间距由块的 `margin` 表达（含负 margin），不是编辑器统一间距。

## 2. 交互契约

| 操作 | 行为 |
|---|---|
| 点击左侧模板卡 | **直接插入**到当前光标所在块之后；未选中则追加到末尾 |
| 点击画布中的块 | 选中该块，右侧面板切换到该块属性 |
| 再次点击已选中的文字块 | 进入文字编辑，光标落到点击位置 |
| 拖动块 | 在投放区内移动；跨投放区时高亮目标区 |
| `Esc` | 退出文字编辑 / 取消选中 |
| 右键 | 上下文菜单：复制、剪切、粘贴、删除、前插空行、后插空行 |
| 悬停块 | 显示块级操作按钮（上移、下移、删除、更多） |
| 工具条 | 随选中对象变化：文字块给字号/颜色/对齐/行距，图片块给裁剪/圆角/链接 |

> 以上「选中/编辑」双态与「点击模板即插入」是秀米的核心手感，我们的工作台按同一契约实现。

## 3. 快捷键（原文取自 `shortcutBinder`）

`⌘` = macOS Command，Windows/Linux 用 `Ctrl`。

### 文档级

| 功能 | macOS | Windows/Linux |
|---|---|---|
| 撤销 | `⌘Z` | `Ctrl+Z` |
| 重做 | `⌘⇧Z` | `Ctrl+Y`（亦接受 `Ctrl+Shift+Z`） |
| 保存 | `⌘S` | `Ctrl+S` |
| 另存为 | `⌘⇧S` | `Ctrl+Shift+S` |
| 新建 | `⌘N` | `Ctrl+N` |
| 打开 | `⌘O` | `Ctrl+O` |
| 预览 | `⌘⌥P` | `Ctrl+Alt+P` |
| 全选块 | `⌘A` | `Ctrl+A` |
| 切换编辑/排版模式 | `⌘/` | `Ctrl+/` |
| 快速预览布局 | — | `Ctrl+Q` |

### 块操作

| 功能 | macOS | Windows/Linux |
|---|---|---|
| 删除 | `Del` / `Backspace` | 同左 |
| 复制 | `⌘C` | `Ctrl+C` |
| 剪切 | `⌘X` | `Ctrl+X` |
| 粘贴 | `⌘V` | `Ctrl+V` |
| 原地复制 | `⌘D` | `Ctrl+D` |
| 前插空行 | `Esc` 然后 `b` | 同左 |
| 后插空行 | `Esc` 然后 `a` | 同左 |
| 冻结单元格 | `⌘⌥⇧Z` | `Ctrl+Alt+Shift+Z` |
| 缩放复位 | `⌘0` | `Ctrl+0` |

### 文字格式

| 功能 | macOS | Windows/Linux |
|---|---|---|
| 加粗 | `⌘B` | `Ctrl+B` |
| 斜体 | `⌘I` | `Ctrl+I` |
| 下划线 | `⌘U` | `Ctrl+U` |
| 删除线 | `⌘K` | `Ctrl+K` |
| 首行缩进 | `⌘⌥\` | `Ctrl+Alt+\` |
| 左对齐 | `⌘⌥[` | `Ctrl+L` |
| 右对齐 | `⌘⌥]` | `Ctrl+R` |
| 居中 | `⌘⌥'` | `Ctrl+E` |
| 两端对齐 | `⌘⌥;` | `Ctrl+J` |
| 分段 | `⌘⏎` | `Ctrl+Enter` |
| 上标 | `⌘⌥↑` | `Ctrl+Alt+↑` |
| 下标 | `⌘⌥↓` | `Ctrl+Alt+↓` |

### 格式刷

| 功能 | macOS | Windows/Linux |
|---|---|---|
| 取格式 | `⌘⌥C` | `Ctrl+Alt+C` |
| 刷格式 | `⌘⌥V` | `Ctrl+Alt+V` |
| 清除格式刷 | `⌘⌥K` | `Ctrl+Alt+K` |

### 修饰键语义

| 组合 | 含义 |
|---|---|
| `⌘` + 点击 | 加选/减选块 |
| `⌥` + 点击 | 穿透选中内部块 |
| `⌘⌥` + 点击 | 穿透并加选 |
| `Ctrl Alt Shift G` | 调试入口（God mode） |
