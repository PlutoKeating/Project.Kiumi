# 本地优先工作台

编辑、换样式、移动、撤销和预览在浏览器执行，复用现有 core 渲染器。Word 导入确认后，不再逐块调用 `/api/render`，避免整页等待。上传、团队保存、签名复制/导出和公众号草稿依然需要服务端。

## 缓存生命周期

- 文稿恢复副本继续按账号和团队存 localStorage。
- 公开模板使用 Cache Storage：分类、目录、完整 HTML/matrix 记录。内存仅保留约 200 个请求结果；大规模数据不塞入容量较小、同步读写的 localStorage。
- 页面先返回本地记录，后台携带 ETag 校验；内容没变返回 304，有变更写入缓存并刷新可见缩略图。已插入文稿的内容不会随模板更新而被覆盖。
- 打开模板面板后后台同步完整目录，再单路逐步缓存所有模板记录。完整目录用于本地分类、搜索、分页；同一模板跨分类的归属保留。可暂停；后台标签页或断网时等待，空间不足、持久写入失败、请求错误时停止并提示。重新打开页面或继续同步可重试，已缓存内容仍可用。
- 首次尚未下载的模板仍需联网；全库同步不是瞬间完成，也不承诺浏览器清理站点数据后保留缓存。
- 公开镜像图片在首次读取后由 Service Worker 持久缓存。首次未读过的图片仍需下载，不预先下载整个图片库。私有 `/uploads/`、会话、团队稿件不进入公共缓存。
- 目录/详情更新检查仍受服务端底层五分钟边缘缓存影响；不是实时推送。

采用浏览器原生 Cache API，不新增缓存框架。依据：[MDN 缓存策略](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Caching)、[存储额度](https://developer.mozilla.org/en-US/docs/Web/API/Storage_API/Storage_quotas_and_eviction_criteria)。

## 卡片样式与编辑

先选中现有块，在模板卡片下点击「应用样式」。保留块 ID、位置、正文顺序、图片、列表和表格合并属性，把语义内容放入目标模板的正文区域，使用新模板的外观与文字样式；整个替换可一次撤销。模板没有可承载正文的文字区域时保持原文并提示。多文字区模板默认选最长正文区域，不自动把文章拆配到标题、署名等多个区域；目标模板的装饰布局保留。对复杂 SVG 交互模板，不承诺自动重映射所有交互语义。

常见“输入文字/请输入文字/输入标题”等占位文案在插入时清空，只在编辑器中显示“双击输入内容”的 CSS 提示，不作为正文导出。空槽可双击输入；已有正文再次编辑不会清空。画布内粘贴使用剪贴板纯文字，继承当前位置的模板样式；需要保留 Word 图片、表格和列表结构时使用「导入内容」。

顶部采用明确的信息栏与操作栏，窄桌面横向滚动操作栏。画布工具和右侧结构工具至少 32×32，删除按钮单独留间隔。

## 验证

`pnpm typecheck`、`pnpm test`、`pnpm --filter @kiumi/web test:e2e`、`pnpm build:web`。

浏览器测试覆盖无 API 即时渲染、持久缓存与断网读取、后台更新、304、未浏览模板同步、本地分类搜索、缩略图复用插入、桌面宽度布局、内容保留换样式及撤销、占位与粘贴样式、小按钮尺寸。真实 Word 样本通过 `KIUMI_WORD_SAMPLE` 注入，不纳入仓库。尚未在浏览器中完成真实 25,745 个模板全量下载验收；自动化使用小目录覆盖同步流程。
