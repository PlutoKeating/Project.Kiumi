# 开发与验收基线

以用户最新确认的以下范围为准，替代早期单用户/本地文件方案。

- 免费公开的桌面公众号排版工具；不做 VIP、移动编辑器和 H5。
- 注册登录后可以新建或加入团队；团队内共享文稿、图片和多个公众号，团队间隔离。
- 图片只用现有自建存储；结构化数据沿用 D1；不新增付费基础设施。
- 模板全部提供，允许实际可用范围内的非致命视觉差异；失效素材移除。
- 现有 SVG 的文字、图片、颜色、动画参数可编辑，采用记录 HTML/DOM 编辑保留复杂结构。
- 输入支持模板、富文本粘贴、Markdown、HTML/公开网页。
- 本地自动恢复、云端保存、文稿列表；不做历史版本。收藏、最近使用、块剪贴板留在本机。
- 全链路：编辑 → 保存 → 图片处理 → 公众号草稿 → 回读 → 微信手机预览。正式发表在微信后台完成。
- 完成批次后必要验证、提交 main 并 push 上线；用户已明确授权。

当前实现与待确认的真实体验见 [HANDOFF.md](HANDOFF.md)。架构见 [ARCHITECTURE.md](ARCHITECTURE.md)，接口见 [API.md](API.md)。验证只覆盖相关行为，不以反复检查代替交付。
