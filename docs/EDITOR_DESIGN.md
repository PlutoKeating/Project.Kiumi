# 编辑工作台与浮动工具栏

工作台已采用蓝粉 iOS 液态磨砂设计，替代上一版素白/鼠尾草皮肤。工作台使用冷白背景、蓝色操作与选中反馈、粉色收藏点缀；28px 磨砂与高光内缘区分工具栏、下拉面板和弹窗。文稿操作移至第一行，插入与工具入口位于第二行。文章正文、模板和导出 HTML 不受皮肤影响。

设计依据为用户当前要求和 Impeccable Operate 模式；方向合同见 `apps/web/.impeccable/surfaces/src-app-tsx.md`。目前为首批实现，最终设计系统替换与全界面视觉审查尚未完成。

## 选中块工具栏

单击画布内容块显示两排工具，默认跟随内容上方；图钉可固定到画布顶部。滚动后超出画布的选中块隐藏跟随工具栏。工具栏受画布边界约束，弹出面板按剩余高度滚动，低位工具栏向上展开。

- 复制到本机块剪贴板、原地复制、复制到微信；删除、收藏模板、打开模板库换样式；转为正文、标题或引用（转换为纯文本，移除原布局）；前后插入空行；格式刷与组件定位。
- 字体、字号、文字颜色、左右/居中/两端对齐、粗体、斜体、下划线、删除线、文字底色、首行缩进、清除文字格式。
- 行间距、字间距、段落间距、左右边距。
- 不透明度、旋转、上下/左右翻转、倒影及其间距/隐藏比例；块内查找替换、清除链接、批量图片宽度与圆角。

格式作用于整个选中块的文字节点，不是富文本选区；所有内容操作进入既有撤销/重做历史。原始模板从 source HTML 编辑，避免写回预览中改写的资源地址；原生块在需要 DOM 编辑时变为保留块 ID 的 HTML 块。复制到微信复用服务端渲染与签名图片流程。工具栏收藏保存完整内容与样式到本机图文收藏，模板收藏入口继续保留；两类收藏均可在左侧复用。

倒影使用 `-webkit-box-reflect`，微信和不同浏览器的支持可能不同，应在发布前核对微信预览。透明度和变换为真实导出 CSS，平台可能过滤不支持的样式。

## 图文设置

头部提供封面上传、更换、移除，完整标题和分享摘要；「更多设置」提供作者与标签。上传沿用团队身份和图片大小限制；错误就地显示。封面、标签保存在文稿 meta，本机恢复与团队保存均保留。公众号草稿弹窗默认读取头部封面。标签仅为文稿元数据，不自动成为公众号平台标签。

## 弹窗与可访问性

导入、团队、公众号草稿与预览使用 body portal，避免被顶栏滚动和磨砂层裁剪。支持 Escape 关闭、焦点循环与关闭后恢复触发按钮焦点；忙碌导入/同步保持原有关闭限制。正文与设置表单分离，选择颜色不会改变工具栏的色彩。

桌面验证宽度为 1280、1440、1920。尊重 reduced-motion；不支持 backdrop-filter 时使用实色回退。基础交互不依赖动画。

## 验证

- `pnpm --filter @kiumi/web test:editor`：格式、撤销、导出 source、不透明度/变换、替换、链接清理、批量图片、空行、元数据恢复、焦点和三种桌面宽度。
- `pnpm --filter @kiumi/web test:e2e`：以上与原 Word/缓存/样式移植回归。
- `pnpm typecheck`、`pnpm test`、`pnpm build:web`。

无新增运行时依赖、密钥或数据库迁移。Impeccable 安装由 `npx impeccable skills install` 完成；本机技能包、二进制、hook 与临时截图被忽略，不进入部署产物。

## 验收与复现

蓝粉玻璃外壳、资源面板、内容导航、团队与公众号表单已完成重构；共享材质、色彩、圆角和动效集中在 `apps/web/src/tokens.css`。文稿预览保持白底，删除文稿/解除绑定使用就地确认，上传失败显示工作台状态。确认支持取消、Escape 和焦点恢复；异步控件失焦后弹窗仍响应 Escape。

`pnpm --filter @kiumi/web verify:ui` 通过类型检查、33 项浏览器测试和生产构建；1 项外部 Word 样本测试因未配置样本跳过。主包约 668 kB，仍有超过 500 kB 的构建提示。本轮没有新增运行时依赖、生产环境变量或部署步骤。

`capture:ui` 在独立浏览器中拦截 API，复现 36 个状态：三种桌面宽度、全部工具菜单、资源加载/失败/空态、导入预览/处理/失败、团队与图库登录状态、删除确认、1280×680 弹窗及工具栏、减少动效与玻璃回退。截图和 manifest 位于忽略目录 `.impeccable/review/current/`。无 backdrop-filter 截图是 CSS 回退模拟，不是旧浏览器兼容认证；真实公众号发布没有执行。

Impeccable detector 唯一提示为文章导入保留的 Arial 字体，不属于编辑器皮肤。独立 finish reviewer 的预览底色、原生确认与状态覆盖三项反馈已落实并复核为 resolved，针对这些修复给出 ship 结论。静态截图不证明动画质量或所有外部业务集成；设计系统以 DESIGN.md、design.json 和当前 tokens 为准。
