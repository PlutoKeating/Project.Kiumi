# 编辑工作台与浮动工具栏

工作台采用蓝粉 iOS 式磨砂玻璃：全屏柔光上漂浮通透面板，用强模糊、顶边细高光和层次投影表达层级，不做粗折射环和指针高光，圆角克制。文章是其中唯一不透明的白纸，真实地从玻璃下穿过。文章正文、模板和导出 HTML 不受皮肤影响。

设计规范见 `apps/web/DESIGN.md`，方向合同见 `apps/web/.impeccable/surfaces/src-app-tsx.md`。

## 布局与职责

- **顶部三胶囊**：左侧是品牌和团队入口；中间胶囊与纸面对齐，放文稿标题、保存、撤销重做，文章从它下面穿过；右侧是预览、公众号草稿、主按钮「复制到公众号」、「⋯」（新建文稿、导出 HTML）和账号。
- **资源岛**：导航与内容是同一张玻璃。模板卡片本身就是插入按钮，悬停出现「插入」「换样式」和收藏星标；内部目录编号不再当作名称显示。同步状态收到底部一行。
- **文章纸面**：标题直接在纸上编辑（发布后也在正文之上）。文稿为空时显示起步引导。纸张高度超过 Dock，玻璃下始终有内容；缩放使用 CSS `zoom`，滚动范围与实际尺寸一致。画布不加载 Tailwind preflight，外壳 reset 止于 `[data-block-content]`；`lib/article-context.ts` 定义唯一的文章阅读语境（border-box、段落零外边距、16px/1.6），画布、模板缩略图、收藏与预览共用，模板在各处外观一致。
- **Dock**：插入标题、正文、图片、分割线、间距，上传、导入，缩放。选中块时插到其后，否则追加到末尾。
- **检查器**：分「内容」「大纲」「图文」。在「图文」时选中内容块自动切到「内容」，「大纲」不跳转；非「图文」标签底部保留上移、下移、复制、删除。有待处理的发布检查时标签旁显示数字。
- **状态提示**：一次性结果用底部 Toast，错误停留更久；不再占用顶栏。

## 选中块工具条

单击画布内容块显示单行工具条，居中跟随内容，绝不遮挡文章标题：优先放块上方，放不下放块下方；块太高时先滚动画布露出顶部；图钉固定到顶部。标题下留有署名行的空间，选中第一块也不遮挡标题。滚出可视区时隐藏。在块之间切换时滑动，首次出现直接就位。菜单一次展开一个，朝空间更大的一侧打开，高度受顶部胶囊和视口限制，每一行都可达。

- 左组（文字）：字体、字号、文字颜色（色板与色值）、粗体、斜体、对齐、间距（行距/字距/段距/边距）、文字格式（下划线、删除线、首行缩进、文字底色、复制/粘贴格式、清除格式）。
- 右组（块）：格式刷、变换组件（换样式、转为正文/标题/引用，转换后移除原布局）、复制（块剪贴板、原地、微信）、收藏、删除、更多、固定。
- 更多：前后插入空行、定位、清除链接、不透明度、旋转翻转、倒影、块内查找替换、批量图片宽度与圆角。

格式作用于整个选中块的文字节点，不是富文本选区；所有内容操作进入既有撤销/重做历史。原始模板从 source HTML 编辑，避免写回预览中改写的资源地址；原生块在需要 DOM 编辑时变为保留块 ID 的 HTML 块。复制到微信复用服务端渲染与签名图片流程。工具栏收藏保存完整内容与样式到本机图文收藏，模板收藏入口继续保留；两类收藏均可在左侧复用。

倒影使用 `-webkit-box-reflect`，微信和不同浏览器的支持可能不同，应在发布前核对微信预览。透明度和变换为真实导出 CSS，平台可能过滤不支持的样式。

## 图文设置

标题在纸面编辑；右侧「图文」提供 2.35:1 分享封面（上传、更换、移除）、摘要（120 字计数）、作者、标签、主题色和发布前检查；标题、正文、封面、摘要未齐前显示待办，不显示通过。上传沿用团队身份和图片大小限制，错误就地显示。封面、标签保存在文稿 meta，本机恢复与团队保存均保留。公众号草稿弹窗默认读取此封面。标签仅为文稿元数据，不自动成为公众号平台标签。

## 弹窗与可访问性

导入、团队、公众号草稿与预览使用 body portal，避免被滚动容器和磨砂层裁剪。支持 Escape 关闭、焦点循环与关闭后恢复触发按钮焦点；忙碌导入/同步保持原有关闭限制。

下拉使用 `ui.tsx` 的玻璃 `Select`（role=combobox/listbox，方向键、Home/End、Enter、Escape，portal 到 body，下方不够时向上翻），不再有原生下拉弹层。

图标按钮都有无障碍名称和延迟出现的提示。伪元素提示文字会进入带文本按钮的可访问名称计算，所以此类按钮必须显式写 `aria-label`。

桌面验证宽度为 1280、1440、1920 及 1280×680。尊重 reduced-motion；不支持 backdrop-filter 时使用实色回退。基础交互不依赖动画。`field-sizing` 不受支持的浏览器中，文本框不随内容自动增高，仍可滚动输入。

## 验证

- `pnpm --filter @kiumi/web test:editor`：格式、撤销、导出 source、不透明度/变换、替换、链接清理、批量图片、空行、元数据恢复、焦点和三种桌面宽度。
- `pnpm --filter @kiumi/web test:e2e`：以上与原 Word/缓存/样式移植回归。
- `pnpm typecheck`、`pnpm test`、`pnpm build:web`。

无新增运行时依赖、密钥或数据库迁移。`capture:ui` 用拦截 API 的示例数据复现 39 个状态，截图位于忽略目录 `.impeccable/review/current/`；无 backdrop-filter 截图是 CSS 回退模拟，不是旧浏览器兼容认证，静态截图也不证明动画质量或真实公众号发布。
