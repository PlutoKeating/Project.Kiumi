# 交付说明

生产入口：https://kiumi.plutokeating.beer 。当前功能、架构、部署方式与验证状态统一维护在 [HANDOFF.md](HANDOFF.md)。

用户流程：登录并创建/加入团队 → 选择模板或导入内容 → 编辑文字、图片、颜色及动画 → 保存文稿 →「公众号草稿」选择公众号与封面 → 保存并同步 → 确认回读结果 → 在微信后台发送手机预览。正式发表在微信后台完成。

必要工程检查：`pnpm typecheck`、`pnpm test`、`pnpm build:web`。测试覆盖渲染、MCP、本地服务和 Worker/D1 团队权限；测试代理不能替代真实微信验证。

素材和模板文件不入 Git。索引包含重复分类引用，不应将索引行数或骨架数写成独立模板的可编辑覆盖率。编辑器使用记录 HTML 保留结构，失效素材直接移除。
