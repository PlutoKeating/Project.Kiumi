# Product

## Platform
web

## Product Purpose
Kiumi 是桌面公众号图文工作台：选择模板、修改内容、导入文档、共享团队文稿，并复制或同步公众号草稿。

## Users
依据现有产品文档：在桌面浏览器制作公众号文章的内容编辑者和团队成员。

## Capabilities and Constraints
React + Zustand + Tailwind，复用 core 渲染与已有团队 API。保留模板、SVG、Word 导入、撤销、本地恢复、团队隔离与微信导出。只做桌面编辑器；不自动发布文章。正文样式独立于编辑器界面。

## Brand Commitments
用户最新反馈：大面积主色为米白或素白，不使用彩色晕染，加强磨砂玻璃质感。用户指定：优雅、清爽、对齐、整洁，柔和明亮底色，低饱和马卡龙点缀，磨砂玻璃质感。截图 1–5 的功能需可用。头部设置和所有弹窗统一优化。工具栏默认跟随选中内容，提供固定切换。

## Evidence on Hand
README.md、docs/ARCHITECTURE.md、docs/API.md 与 apps/web 现有实现。用户提供九张界面参考截图。
