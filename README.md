## 怎么用

1. 打开上面的网址。
2. 在左侧点一个模板缩略图，它会出现在中间的文稿里。
3. 选中已有内容块后，把鼠标移到模板卡片上点「换样式」，内容保留、外观更换；双击文字就能改，粘贴文字自动沿用模板字体和颜色；选中任意一块，上方工具条调字号和颜色，右侧「内容」改文字和图片。
4. 点「复制到公众号」，到公众号后台粘贴；也可登录后在「公众号草稿」选择团队公众号、封面，直接同步草稿。
5. 已有 Word/WPS `.docx`、富文本、Markdown、网页内容，或从秀米复制的内容 / 秀米预览链接，可用底部 Dock 的「导入」先预览，再分块追加、插入或新建文稿。带图导入需登录并选团队，图片总量上限 80 MB。
6. **投递包一键排版**：在模板卡片上点「排入稿件」选定风格，再拖入「Word + 原图」的 ZIP，自动识别标题/小标题/正文/署名，把 Word 里的占位图换成压缩包里的原图；配置了模型时由 AI 按所选风格编排（可重复或跳过模板单元、为小标题条拟写短标题），否则按规则排入，任何段落和图片都不会因模板放不下而丢失，并套用团队排版规范；把握低的识别和匹配会标黄，可逐项改。配置了「版面精修」模型时，AI 会看着排好版面的截图逐步修改（标题被裁、文字重叠、样例图残留等），直到满意，过程在预览里实时可见，随时可停。图片在预览期间就在后台上传。详见 [稿件导入与自动排版](docs/MANUSCRIPT.md)。
7. **模型配置**：站点管理员在账号菜单「模型配置」（`/admin`）从 models.dev 目录添加提供商、录入 Key、勾选模型并排定调用顺序，保存即生效，见 [模型配置](docs/MODELS.md)。
8. **AI Agent 接入**：Agent 经远程 MCP 登录后可建稿、导入、微调、审稿，修改会实时出现在画布上，见 [MCP](docs/MCP.md)。

## 界面结构

![界面说明](docs/images/ui-map.svg)

| 位置 | 作用 |
|---|---|
| 左上胶囊 | 品牌与团队入口 |
| 顶部中间胶囊 | 当前文稿、保存、撤销与重做 |
| 右上胶囊 | 预览、公众号草稿、复制到公众号；「⋯」里新建和导出 HTML |
| 左侧资源岛 | 模板、素材、收藏、剪贴板、图库；点一下就用 |
| 中间纸面与底部 Dock | 你的文稿，看到的就是发出去的样子；Dock 在选中块之后插入内容、上传、导入、缩放 |
| 右侧检查器 | 「内容」改所选块，「大纲」排顺序，「图文」设封面、摘要、作者、标签、主题色并看发布前检查 |

## 常用操作

| 想做的事 | 怎么做 |
|---|---|
| 改文字 | 在画布上双击那段文字 |
| 改一部分文字的格式 | 双击进入编辑，拖选文字，再用工具条改字号、颜色、加粗等；不选文字时作用于整块 |
| 换图片 | 选中那块，在右侧「内容」上传替换或填图片地址 |
| 调整顺序 | 在右侧「大纲」里拖动 |
| 换个颜色 | 在右侧「图文」点主题色，能换色的模板会一起变色 |
| 统一格式 | 选中一块按 `Ctrl+Alt+C` 取格式，再选另一块按 `Ctrl+Alt+V` |
| 撤销 | `Ctrl+Z` |
| 删除 | 选中后按 `Delete` |
| 换顺序 | 直接拖动块，或用悬停时块右上角的箭头 |
| 选中别的块 | `↑` `↓` 逐块移动，`Esc` 取消选中 |
| 插入空行 | 在画布上右键，或工具条「⋯」里选「前插空行」「后插空行」 |

登录后可创建或加入团队，在左上角团队入口里保存、打开稿件和邀请成员。文稿与图库在团队内共享、团队间隔离。未登录也能排版，文稿自动保留在本机。

## 模板和图片放在哪里

模板和图片保存在自己的数据服务里，由这台服务提供给网站。仓库里只有代码，没有模板和图片。

秀米「风格排版」店铺与内置模板共用同一套目录和编辑器：`kiumi crawl shop-list` 先枚举店铺列表，`kiumi crawl shop` 再把预览页里的成品 HTML 落成 `shop:paper/*` 记录并并入 `modern-index.json`。店铺单条常引用几十张图，首轮不逐张镜像，由 `/api/shop-image` 同源代理并在边缘缓存；后续可分批镜像。

## 给开发者

```bash
pnpm install
pnpm dev        # 本地 API 与工作台
pnpm test
```

| 目录 | 内容 |
|---|---|
| `packages/core` | 排版引擎：把模板和数据变成最终 HTML |
| `packages/catalog` | 模板整理与素材同步 |
| `packages/sdk` | 给命令行、MCP、服务端共用的接口 |
| `packages/cli` | `kiumi` 命令行 |
| `packages/mcp` | 本地开发用的 stdio MCP；生产的远程 MCP 在 `apps/edge/src/mcp.ts` |
| `apps/edge` | Cloudflare Worker，同时提供网页与接口 |
| `apps/web` | 浏览器里的工作台 |
| `apps/server` | 本地服务，用于查看素材与推送草稿 |
| `deploy/ecs-data` | 数据服务：只读目录与素材，另负责图片写入、微信代理和稿件 ZIP 处理（sharp） |

命令行常用的几条：

```bash
kiumi list --room <分类> --q <关键词>
kiumi render --tpl <模板编号> --set 'txt1=<p>标题</p>' -o out.html
kiumi validate out.html
kiumi audit
```

更细的说明在 [`docs/`](docs/)。

## 编辑工作台

选中内容即可使用跟随工具条：字体、对齐、间距、旋转翻转、文字替换和图片批处理；支持固定到顶部与撤销。分享封面、摘要、作者、标签和主题色都在右侧「图文」。界面为蓝粉 iOS 式磨砂玻璃：工具是悬浮的通透面板，文章是其中唯一不透明的白纸。详情与兼容边界见 [编辑工作台](docs/EDITOR_DESIGN.md)。
